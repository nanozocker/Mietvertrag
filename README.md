# Wohnraummietvertrag Peterstraße 27, 64683 Einhausen (EG)

Kombinierter Mietvertrag mit entsprechenden Anhängen:

- **Mietvertrag-komplett-Peterstrasse-27-EG.doc** – enthält den kompletten Vertragstext inkl. Anhang 1 (Heizen & Lüften), Anhang 2 (Hausordnung) und Anhang 3 (Datenschutz-Info). Diese Datei ist eine Word-kompatible HTML-Datei: einfach in Word öffnen und dann unter **Datei → Speichern unter → Word-Dokument (.docx)** sichern.
- **Mietvertrag-komplett-Peterstrasse-27-EG.md** – dieselbe Fassung als reine Textfassung (Markdown), z. B. zum Gegenlesen.

## So kommst du an die Word-Datei

1. Auf die Datei **Mietvertrag-komplett-Peterstrasse-27-EG.doc** klicken
2. Oben rechts im Datei-Fenster: **Raw** bzw. Download-Symbol (pfeil nach unten) anklicken → Datei landet in „Downloads"
3. Datei mit **doppelklicken** oder in Word über **Datei → Öffnen** öffnen (ggf. „Alle Dateien" als Dateityp wählen)
4. In Word: **Datei → Speichern unter → Word-Dokument (*.docx)** wählen
